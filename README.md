# fluxr-media

Public pictures and videos for Fluxr's social posts. Media only: the notes, plans and numbers live in a private repo.

- `posts/`: finished videos and pictures, one file per post (`<date>-<country>-<what>.<ext>`), linked by commit-SHA raw URLs.
- `assets/`: flags, logos and backgrounds used to build flyers (uploaded to Canva from their raw URLs).
